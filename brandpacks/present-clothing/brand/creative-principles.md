# Present Clothing — Creative Principles

> **Status: ACTIVE. Layer 2 — long-lived.**
> Rarely changed. Amendment requires a stated reason logged to
> `campaign-memory.md`. A principle is not dropped because a campaign found it
> inconvenient.

Supporting document. Not contract-governed. Derives from `brand-laws.md`.
Parent of `visual-identity.md` and `brand-voice.md`.

**These principles state why the execution rules exist. `visual-identity.md`
and `brand-voice.md` state how they are executed.**

---

## The Principles

### P1 — Enter in the middle, leave before the end

*Serves L2.*

Begin after it started. Stop before it finishes. No setup, no resolution, no
threshold crossing, no arrival.

**Test:** is the first frame a beginning? Is the last frame a conclusion? Both
must be no.

### P2 — Evidence over description

*Serves L4.*

Weight, hour, place, technique, number. State the fact and stop. The reason
given is construction-based, never benefit-based.

**Test:** does any word name an emotion, a value, or a benefit? Fail.

### P3 — Reward attention

*Serves L5.*

Every film, photograph, garment and experience reveals more on a second
encounter than on the first.

**Test:** name the thing a second encounter reveals that the first did not. If
you cannot name it, it is not there.

| Craft | What the second encounter yields |
|---|---|
| Film | A detail in the background that reads only once you stop watching the subject |
| Photography | A construction detail present but never centred |
| Copy | A fact whose significance lands after you know the garment |
| Garment | A decision you find in month three, not in the shop |
| Campaign | A location you recognise from a film two years old |

This is the principle that makes L5 worth obeying — return is only rewarded if
there is something to return to.

### P4 — Withheld address

*Serves L1.*

The work is observed, not delivered. The viewer is a witness, not a target.

**Test:** is the viewer addressed, greeted, hooked, or looked at? Fail.

### P5 — The unremarkable instance is the strongest subject

*Serves L3.*

The day with nothing to show for it. Not the exception — the repetition.

**Test:** would the subject themselves have posted this moment? If yes, it
contains a result and is the wrong moment.

## Derivation chain

```
Brand Laws → Creative Principles → Visual Identity / Brand Voice → Campaigns
```

Every rule in `visual-identity.md` and `brand-voice.md` cites the principle it
serves. Any rule that cannot complete the chain is not a brand rule. It is a
preference, and it is deleted.

Worked example:

```
24fps, no slow motion              ← execution (visual-identity.md)
serves P4 withheld address          ← slow motion claims significance
serves L1 want nothing              ← a claim is a request for agreement
```

---

## Exceptions

A Principle is bent only with a logged reason. The log records layer, rule,
reason and piece, and is written to `campaign-memory.md`.

An unlogged exception is a failure, not a judgment call.

---

## Layer 3 note

Execution — cinematography, photography, motion, lighting, lens, framing,
editing, sound and copy — lives in `visual-identity.md` and `brand-voice.md`.
Those documents version freely and are reviewed every two collections.

A separate `execution-rules.md` is deliberately **not** created. It will be
introduced only if a real operational problem appears: multiple photographers,
videographers, agencies, or conflicting implementations.
