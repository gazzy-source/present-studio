# production-blueprints/

Reusable output specifications — brand-agnostic.

A blueprint defines how a class of deliverable is produced: its structure, its
required inputs, the adapters involved, the standard it must meet.

**Depends on:** `foundation/`, `contracts/`, `engines/`, `adapters/`.

Rendered production output lives in `brandpacks/<brand>/production/`. This folder
holds the specification; the brand pack holds the result.

If it names a brand, it belongs in a brand pack.
