# foundation/

The invariants of the operating system. The kernel.

Holds what "premium" means operationally, the quality bar every artifact is
judged against, and the shared taxonomy the rest of the system speaks in.

**Depends on:** nothing.
**Read by:** everything.

Changes here propagate to every engine, every adapter and every brand pack.
Treat edits as breaking changes.

Brand-specific material never belongs here.
